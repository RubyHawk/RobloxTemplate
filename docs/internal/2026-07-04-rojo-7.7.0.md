# Rojo 7.7.0 upgrade — 2026-07-04

## Official source

- Rojo 7.7.0 release: <https://github.com/rojo-rbx/rojo/releases/tag/v7.7.0>

Checked on 2026-07-04. This is the stable full release, not the earlier release candidate.

## Decision

The repository pins `rojo-rbx/rojo@7.7.0` through Rokit and installs the matching Studio plugin with `rojo plugin install`.

The release changes live sync from long polling/JSON to WebSockets/MessagePack, adds host validation for safer local serving, improves resync matching, and introduces `rojo syncback`. Syncback is not run broadly against the workbench: it must first be constrained to a dedicated UI project and reviewed so it cannot overwrite scripts, unrelated presets, or independent GUI trees.
