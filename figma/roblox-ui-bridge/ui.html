1. Import authored UI

Choose one or more Rojo *.model.json files. Nested world UI is found automatically. Everything is placed on the current page, so this works with Figma Starter's three-page limit.

2. Export visual edits

Select one or more imported artboards to export only those. Clear the selection to export every mapped UI layer on this page.

Roblox stays authoritative

Container placement, Adornee/Face, scripts, asset IDs, and runtime behavior stay in Roblox. The bridge updates the child Frames, text, images, sizing, colors, corners, and strokes.
