# RNG Defender Figma icon kit

This kit packages the project's licensed Gvesster Basic artwork for direct use with
the Figma agent.

- Attach `contact-sheet.png` with the UI references so the agent can see the full
  icon language.
- Extract `rng-defender-icons.zip` and attach the individual PNGs needed by the
  selected screen. The filenames describe their intended UI roles.
- Prefer the supplied PNGs over generated or generic line icons.

The `core` group comes from the tracked sources in
`assets/icons/gvesster-basic`. The `gameplay` group contains selected additions
from the licensed local picker used by the project.

These PNG files are design sources, not proof of Roblox cloud availability.
Runtime roles must still be promoted through `ICON_LIBRARY.cmd` and
`assets/icons/icon-manifest.json` before Roblox code depends on them.

Source artwork is from **Free Icon Pack v3.1 (Basic)** by `@gvesster`. Do not
redistribute this kit separately from the project.
